# Python Basic Projects

A collection of beginner-friendly Python projects created to practice programming fundamentals, problem-solving, and core Python concepts.

## 📌 About

This repository contains simple Python projects suitable for beginners who are learning:

- Variables and data types
- Conditional statements
- Loops
- Functions
- Lists, tuples, sets, and dictionaries
- File handling
- Exception handling
- Object-oriented programming
- Basic modules and libraries

## 📂 Projects

Some projects included in this repository are:

- Calculator
- Number Guessing Game
- Rock Paper Scissors
- Password Generator
- To-Do List
- Temperature Converter
- Quiz Game
- Contact Book
- Simple Banking System
- Word Counter

> More projects will be added as the repository grows.

## 🛠️ Requirements

- Python 3.x

You can download Python from the official website:

https://www.python.org/downloads/

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/yashbasargekar05/Python-Basic-Projects.git
```

2. Navigate to the project directory:

```bash
cd Python-Basic-Projects
```

3. Run any Python file:

```bash
python filename.py
```

For example:

```bash
python calculator.py
```
